# The stroke fonts

`drip.ts` is generated by `scripts/drip-font.mjs`, which draws it: Drip is
this project's own hand, under the project's licence. `goo.ts` is
generated by `scripts/goo-font.mjs`: Goo's lowercase is this project's own
drawing too, its capitals and marks Drip's.

| File | Font | Licence |
| --- | --- | --- |
| `drip.ts` | Drip, drawn for Pasty and Pasty Flat | This project's |
| `goo.ts` | Goo, drawn for Stickery's Goo | This project's |
