# The stroke fonts

The files beside this one are generated by `scripts/extract-strokes.mjs`
from the SVG fonts in the [hersheytext](https://github.com/techninja/hersheytextjs)
package (MIT; its Hershey font data public domain).

| File | Font | Licence |
| --- | --- | --- |
| `elfin.ts` | EMS Elfin, by Sheldon B. Michaels, SVG conversion by Windell H. Oskay; a derivative of Mountains of Christmas by Crystal Kluge (Tart Workshop) | SIL Open Font License 1.1 (Google Fonts cites Apache 2.0 for the original) |
| `felix.ts` | EMS Felix, by Sheldon B. Michaels, SVG conversion by Windell H. Oskay; designer Fontstage | SIL Open Font License 1.1 |
| `script.ts` | Hershey Script 1-stroke, by Dr. A. V. Hershey; SVG fonts by Windell H. Oskay, Evil Mad Scientist | Public domain |
| `sans.ts` | Hershey Sans 1-stroke, by Dr. A. V. Hershey; SVG fonts by Windell H. Oskay, Evil Mad Scientist | Public domain |

The SIL Open Font License is in `OFL.txt` beside this file. The fonts are used
here as stroke data drawn into pictures, are not sold on their own, and keep
their names in this notice.
